# Mini Printer — Product Landing Page

Responsive product landing page for a compact Bluetooth thermal printer.

The project presents the product, its key features and specifications, and provides a simple order form for potential customers.

## Features

- Responsive layout for desktop, tablet and mobile
- Product-focused hero section
- Feature overview
- Product gallery
- Price and promotional offer
- Order form
- Product specifications
- Delivery flow
- Smooth navigation and clear calls to action

## Technologies

- HTML5
- CSS3
- Responsive Design
- Netlify Forms
- Google Fonts

## Project Goal

The goal of the project is to create a clean, modern and conversion-focused landing page for a physical product while keeping the implementation lightweight and fast.

## Status

The project is currently being prepared as a portfolio-ready commercial case.

## Development

No build process is required.

Clone the repository and open `index.html` in a browser.
